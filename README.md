javascriptのコーディング練習ができるアプリです。

## 使用技術

- React
- Typescript
- Vite
- CSS

## 概要
[こちら](https://react-road.b13o.com/challenges/code-challenge-app) のチャレンジ内容を
実装しました。  
練習問題が3問あり、その答えを出力するコードの記載・実行・取り消しができます。
実行を押すと、想定回答と同じ回答が得られるかを基準に採点されます。
